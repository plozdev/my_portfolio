# Design System & Aesthetics (Look and Feel)

This document defines the exact visual identity, mood, and aesthetic guidelines for the personal portfolio. When generating UI designs, you must strictly adhere to the vibes and rules outlined below.

## 1. Core Vibe & Theme
- **Keywords:** Premium, Modern, Developer-Focused, Sophisticated, High-Tech, Elegant.
- **Overall Mood:** The portfolio should feel like a high-end SaaS product or a cutting-edge tech startup's landing page. It should not look like a standard, generic blog. It must command respect and immediately communicate "highly skilled engineer."

## 2. Color Palette
The website exclusively uses a **Dark Mode** aesthetic to create depth and contrast.

- **Backgrounds:** 
  - Primary: Deep, rich charcoal or slate (e.g., almost black, but with a slight blue or purple undertone, like `#0A0F1A` or `#0F172A`).
  - Secondary/Cards: Slightly lighter, translucent variants of the background to create elevation.
- **Text:** 
  - Primary: Bright, crisp white (`#FFFFFF` or `#F8FAFC`) for high readability.
  - Secondary: Soft, muted grays (`#94A3B8`) for descriptions and less important text.
- **Accents (The "Pop"):**
  - Choose one or two vibrant, elegant accent colors. Recommended pairings: **Emerald Green & Cyan**, or **Deep Violet & Electric Blue**. 
  - Use these sparingly for buttons, link hover states, icons, and subtle gradient borders. Do not overwhelm the dark background.

## 3. Depth, Texture & Shapes
- **Glassmorphism:** This is a core design element. Cards (like for Experience or Projects) should use translucent backgrounds with a background-blur effect to let subtle colors shine through from behind.
- **Borders & Glows:** Use ultra-thin (1px), semi-transparent borders on cards. Add very soft, subtle, colored glow effects behind important elements (like the Hero text or featured project cards) to create a sense of light in the dark environment.
- **Corners:** Use medium to slightly rounded corners (`border-radius: 8px` to `12px`) for a modern, friendly, yet professional feel. Avoid sharp, aggressive right angles.

## 4. Typography
- **Font Choice:** Use modern, geometric, sans-serif fonts (e.g., Inter, Roboto, Outfit, or Plus Jakarta Sans). 
- **Hierarchy:**
  - **Headings:** Bold, punchy, and large. Consider using subtle text gradients (e.g., white fading to light gray, or an accent color gradient) for major section titles.
  - **Body:** Clean, well-spaced (high line-height), and easy to read. 
- **Monospace Accents:** For technical elements (like tags for "Java" or "React", or small code snippets), use a clean monospace font (like JetBrains Mono or Fira Code) to reinforce the "Software Engineer" identity.

## 5. Interaction & Motion (The "Feel")
The website must feel "alive" and highly responsive to the user.

- **Hover States:** Every interactive element (buttons, project cards, links) must react when hovered. Cards should slightly scale up or elevate (shadows become brighter/colored).
- **Scroll Entrances:** As the user scrolls down, sections and cards should smoothly glide and fade into view from the bottom. Nothing should appear abruptly.
- **Micro-interactions:** Buttons or tags might have a subtle shimmer effect or a border-tracing animation to draw the eye.

## 6. Layout & Whitespace
- **Breathing Room:** Use extensive whitespace (negative space) between sections and elements. A premium design never feels cluttered. Let the text and the cards breathe against the dark background.
- **Asymmetry & Grids:** While lists (like Experience) might be straight columns, use dynamic grid layouts for Projects or Skills (e.g., masonry grids, or alternating left/right image placements) to keep the eye engaged.

## Summary for the Designer
Your goal is to make the user say "Wow" within the first 3 seconds. Rely heavily on the dark background, the blurred glass elements, the vibrant accent glows, and pristine typography to achieve a state-of-the-art look.
