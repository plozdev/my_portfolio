## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm, pnpm, or yarn

### Installation & Run Locally
```bash
# Clone the repository
git clone https://github.com/plozdev/my_portfolio.git
cd my_portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
